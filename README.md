A one-letter entry for make.fun's "One Letter for Your Day": it writes exactly `Z` — zero sleep — to `/output/entry.txt`, and nothing else. One letter, one long night, zero sleep.

The word behind the letter is "zero sleep": a whole day with no sleep at all, told in a single letter — vivid, funny, and true to anyone who has pulled an all-nighter.
